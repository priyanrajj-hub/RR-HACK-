## 🚀 How to Run and Reproduce

### 1. Run Automated Pytest Test Suite
```bash
python -m pytest -v tests/
# Output: 15 passed in 1.08s (100% pass rate)
```

### 2. Run Core Sabermetric Pipeline & Generate Artifacts
```bash
# Core pressure calculations, expected models & empirical Bayes shrinkage
python analysis.py

# Recompile exact 5-page PDF methodology report
python build_report.py
```

### 3. Launch Local Dashboard & API Backend
```bash
# Start Next.js 14 WebGL frontend
cd dashboard
npm install --legacy-peer-deps
npm run dev
# Open http://localhost:3000 in your browser
```
